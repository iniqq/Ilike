# Mace Swap — Minecraft 1.21.11 (Fabric)

Port of maceswap-1.0.0 (originally built for 26.2) to Minecraft 1.21.11.

## Build
Requires JDK 21.

    ./gradlew build        (Windows: gradlew.bat build)

The finished mod is `build/libs/maceswap-1.0.0.jar` (ignore the `-sources` jar).
Put it in your `.minecraft/mods` folder with Fabric Loader 0.18+ and Fabric API for 1.21.11.

## Keybinds (Controls -> Misc)
U = Mace Swap, I = Breach Swap, O = Smart Swap, Right Shift = config menu.
